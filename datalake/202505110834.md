```bash
Cannot open /var/log/sysstat/saXX: No such file or directory
Please check if data collecting is enabled
```



comes from tools like sar (from the sysstat package) and means that no performance data was recorded for the 11th day of the month.
To fix this:
✅ 1. Ensure sysstat is installed

`sudo apt install sysstat       # Debian/Ubuntu`
# OR
`sudo yum install sysstat       # RHEL/CentOS`

✅ 2. Enable data collection

On Debian/Ubuntu, edit /etc/default/sysstat:

`sudo nano /etc/default/sysstat`

Set:

`ENABLED="true"`

On RHEL/CentOS, ensure sysstat is enabled in /etc/sysconfig/sysstat.
✅ 3. Enable and start the cron or timer

    On systemd-based systems (modern Debian/Ubuntu/CentOS 7+):

sudo systemctl enable sysstat
sudo systemctl start sysstat

    On cron-based systems, verify the cron job exists in /etc/cron.d/sysstat.

✅ 4. Wait for data to be collected

Data is collected periodically (usually every 10 minutes). It will take time before daily files like /var/log/sysstat/sa11 are created.
✅ 5. Check if data files exist

ls /var/log/sysstat/

You should see files like sa11 (binary) and sar11 (human-readable).
