You're seeing the Git prompt for username and password because your remote is using **HTTPS instead of SSH**. To "get back to SSH" and avoid these prompts, you need to:

---

### 1: Verify You Have an SSH Key

If you don’t already have one:

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```

Then add the key to your agent:

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

---

### 2: Add Your Public Key to GitHub

```bash
cat ~/.ssh/id_ed25519.pub
```

Copy the output, then:

1. Go to **GitHub** → **Settings** → **SSH and GPG keys**
    
2. Click **New SSH key**
    
3. Paste it and save.
    

---

### 3: Change Your Git Remote to Use SSH

Check your remote:

```bash
git remote -v
```

You'll likely see:

```
origin  https://github.com/yourname/yourrepo.git (fetch)
origin  https://github.com/yourname/yourrepo.git (push)
```

Change it to SSH:

```bash
git remote set-url origin git@github.com:yourname/yourrepo.git
```

Then verify:

```bash
git remote -v
```

Now you'll see:

```
origin  git@github.com:yourname/yourrepo.git (fetch)
origin  git@github.com:yourname/yourrepo.git (push)
```

---

### 4: Push Without Prompts

```bash
git push origin master
```

No username/password prompt now — it uses your SSH key instead. ✔️
