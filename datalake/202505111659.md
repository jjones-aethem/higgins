# Formatting Strings in Go

```go
package main

import "fmt"

func main() {
	const name = "Saul Goodman"
	const openRate = 30.5

	msg := fmt.Sprintf("Hi %s, your open rate is %.1f percent\n", name, openRate)


	fmt.Print(msg)
}
```

### Explanation:

- `fmt.Sprintf` is used to format a string without printing it immediately.
    
- `%s` formats the `name` string.
    
- `%.1f` formats the `openRate` to **one decimal place** (tenths place).
    
- `\n` adds a newline at the end.
